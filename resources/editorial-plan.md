# 世勢觀察編輯計畫

## 定位

世勢觀察是一個「分析型部落格 + 電子報」格式的國際局勢內容站。首頁第一任務是讓新訪客在幾秒內理解：這裡不是即時新聞站，而是提供脈絡、利益關係、風險傳導與下一步觀察指標。

## 讀者

- 想穩定掌握國際局勢的專業工作者
- 關注台海安全、全球市場、能源與科技治理的讀者
- 不想每天追大量新聞，但需要每週整理的人

## 欄目

- 本週主線：每週一篇 1200 到 1800 字分析，回答一個核心問題。
- 三分鐘世勢：短篇解釋一個事件的背景、利益方與後續觀察點。
- 觀察清單：整理下週三個數據、兩場會議、一條值得追蹤的風險線。

## 首頁結構

1. 頂部導覽：最新文章、專題、Start Here、訂閱。
2. 首屏：清楚定位、一篇本週主文、email 訂閱表單。
3. 最新文章：三篇內容示例，讓訪客看到文章品質。
4. 專題入口：中美與地緣政治、全球經濟與能源、科技與治理。
5. Start Here：新讀者先讀的代表文章。
6. 頁尾訂閱：再次提供簡短訂閱理由。

## 發刊節奏

- 每週二：主線電子報
- 每週四：短篇解析
- 每月最後一週：月度風險地圖

## 文章模板

每篇文章固定包含：

- 重點摘要
- 發生了什麼
- 為什麼重要
- 關鍵利益方
- 經濟或安全傳導路徑
- 接下來看什麼

## 訂閱技術備註

目前 `assets/js/subscribe.js` 使用瀏覽器 localStorage 模擬訂閱成功，方便設計預覽。正式上線時，把表單 submit 改接任一電子報服務：

- Substack embed
- Buttondown API
- Mailchimp form action
- 自架後端 API
